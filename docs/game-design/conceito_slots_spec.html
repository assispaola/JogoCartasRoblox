Slots de Base — 3 estados

Cada Slot de Base existe em um de 3 estados. Os 33 espaços totais já são desenhados no chão desde o ciclo 0 — o que muda entre eles é só o estado, nunca a posição/layout. Especificações abaixo prontas pra implementar em Roblox UI (Frame + UICorner + UIStroke).

Trancado
locked / não desbloqueado
  • fill#0d1024
  • stroke1.5px dashed #3a355c
  • corner radius10px
  • conteúdonúmero do slot + cadeado
  • número28px, #3a355c
  • sub-label"CICLO N" do unlock, 8px mono
  • interaçãonenhuma (não clicável)
  • regra de unlock+1 slot a cada 2 ciclos
Desbloqueado — vazio
unlocked / sem carta
  • fill#171b34
  • stroke2px solid #C9A959
  • glow0 0 8px rgba(201,169,89,.3)
  • conteúdoícone "+" tracejado, central
  • label"EQUIPAR", 9px mono
  • interaçãotap → abre Mochila
  • $/s gerado0 (slot vazio não gera)
Desbloqueado — ocupado
unlocked / com carta
  • fill#171b34
  • stroke2.5px solid = cor da raridade
  • glowcor da raridade, opacity .10
  • conteúdominiatura da arte da carta
  • rótulo raridadecor da raridade, 9px
  • $/s#4ade80, 10px mono
  • interaçãotap → preview/trocar carta
  • fonte da corRarities.lua (não fixa)
